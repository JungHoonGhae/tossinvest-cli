# TUI/UX 고도화 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ID/심볼을 외워야 하던 지점에 TTY 대화형 선택을 더하고, 핵심 출력에 한국식 손익 색·정렬을 입힌다 — AI/스크립트 경로(플래그·JSON·비TTY)는 불변.

**Architecture:** `internal/tui`에 `PickFromList`(huh Select 래퍼) 추가; 대상 커맨드는 식별자 미지정+TTY일 때만 목록 조회→선택. `internal/output/style.go`에 `colorEnabled` 게이트+lipgloss 스타일; 렌더러는 게이트가 켜질 때만 색을 입힌다(비TTY/NO_COLOR/json/csv는 기존과 바이트 동일).

**Tech Stack:** Go 1.25, cobra, charmbracelet `huh`(기보유, internal/tui 격리), `lipgloss`(스타일, 직접 의존 승격 — 이미 모듈 그래프에 존재).

설계: `docs/superpowers/specs/2026-06-27-tui-ux-design.md`.

## Global Constraints

- AI 우선: 식별자(플래그/인자)가 주어지면 선택 스킵(완전 비대화형). 비TTY+미지정이면 프롬프트 없이 에러(대기 금지).
- **출력 색 게이트(안전 핵심)**: 색 = `format==FormatTable && stdout이 char-device(TTY) && os.Getenv("NO_COLOR")==""`. 게이트 false면 **스타일 0 → 출력이 현재와 바이트 동일**(기존 fixture/계약 테스트 보존, AI 파이프 불변). json/csv는 절대 스타일 없음.
- 한국식 손익 색: 양수=빨강, 음수=파랑, 0=기본.
- `huh`는 `internal/tui`에만. `internal/output`은 huh를 import하지 않는다(자체 stdlib char-device 체크 사용); `lipgloss`만 output에서 사용.
- 거래 안전 불변: 선택은 식별자만 채울 뿐, 기존 게이트·preview·`--execute/--confirm`은 그대로.
- Go stdlib + 기존 의존 + lipgloss. 더미 데이터 테스트.

```go
package tui

import (
	"fmt"
	"os"

	"github.com/charmbracelet/huh"
)

type Item struct {
	ID    string
	Label string
}

func PickFromList(title string, items []Item) (string, error) {
	return pickFromListWith(os.Stdin, os.Stdout, title, items)
}

func pickFromListWith(in, out *os.File, title string, items []Item) (string, error) {
	if len(items) == 0 {
		return "", fmt.Errorf("선택할 항목이 없습니다")
	}
	if !IsInteractive(in, out) {
		return "", ErrNotInteractive
	}
	opts := make([]huh.Option[string], 0, len(items))
	for _, it := range items {
		opts = append(opts, huh.NewOption(it.Label, it.ID))
	}
	var selected string
	form := huh.NewForm(huh.NewGroup(
		huh.NewSelect[string]().Title(title).Options(opts...).Value(&selected),
	))
	if err := form.Run(); err != nil {
		return "", err
	}
	return selected, nil
}
```

```go
package output

import (
	"io"
	"os"

	"github.com/charmbracelet/lipgloss"
)

func isTerminalWriter(w io.Writer) bool {
	f, ok := w.(*os.File)
	if !ok {
		return false
	}
	fi, err := f.Stat()
	if err != nil {
		return false
	}
	return fi.Mode()&os.ModeCharDevice != 0
}

func colorEnabled(w io.Writer, format Format) bool {
	return format == FormatTable && os.Getenv("NO_COLOR") == "" && isTerminalWriter(w)
}

var (
	styleUp   = lipgloss.NewStyle().Foreground(lipgloss.Color("9")) // 빨강 (KR: 상승/이익)
	styleDown = lipgloss.NewStyle().Foreground(lipgloss.Color("12")) // 파랑 (KR: 하락/손실)
	styleDim  = lipgloss.NewStyle().Faint(true)
	styleBold = lipgloss.NewStyle().Bold(true)
)

func profitText(s string, value float64, enabled bool) string {
	if !enabled {
		return s
	}
	switch {
	case value > 0:
		return styleUp.Render(s)
	case value < 0:
		return styleDown.Render(s)
	default:
		return s
	}
}

func dimText(s string, enabled bool) string {
	if !enabled {
		return s
	}
	return styleDim.Render(s)
}

func boldText(s string, enabled bool) string {
	if !enabled {
		return s
	}
	return styleBold.Render(s)
}
```
