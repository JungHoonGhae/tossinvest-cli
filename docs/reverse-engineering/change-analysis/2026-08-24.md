## 변경 요약

`tools/openapi_diff.py` 결과, 신규/삭제된 경로·스키마는 없고 필드 설명(description) 변경만 발생했다.
`[미분류 변경]` 절도 같은 필드의 부수 변경(enum 배열 값 추가)이라 별도 조사로 확인 완료 — 미확인 잔여 없음.

### `timeInForce` — 국내(KR) 주식 시가단일가(OPG) 주문 정식 지원

1. **`Order.timeInForce` (응답 스키마) description**
   - 기존: `OPG`: 장 개시 주문 (At the Opening). **현재는 지원하지 않습니다.**
   - 변경 후: `OPG`: 장 개시 주문 (At the Opening, **국내 시가단일가**).
   - enum 값 자체(`DAY`/`CLS`/`OPG`)는 이전부터 동일 — 응답 스키마는 이미 `OPG` 를 문서화해 두었으나 "미지원" 각주만 있었음.

2. **`OrderCreateRequest.oneOf[0].properties.timeInForce` (요청 스키마, 수량 기반 주문)**
   - `enum`: `["DAY", "CLS"]` → `["DAY", "CLS", "OPG"]` (요청 바디에 `OPG` 사용 가능해짐)
   - description 에 조건 추가: *"현재 국내 주식 전용이며 `orderType` 은 `LIMIT`/`MARKET` 모두 지원합니다. 세션 시간(장전 사전접수) 외 접수는 원장에서 거절될 수 있습니다."*

즉 이번 변경은 신규 필드/엔드포인트가 아니라, 이전부터 응답 스키마에 예약되어 있던 `OPG` 값을 **요청 스키마에서도 실제로 허용**하도록 활성화한 것이다 (국내 주식, `LIMIT`/`MARKET` 공통, 장전 시간외 접수는 원장 거절 가능).

## 분류

**(b) 신규 기능 후보**

- Breaking 위험 없음: 기존 요청/응답 필드 삭제나 타입 변경이 아니고, CLI 는 애초에 `DAY` 외 값을 보내지 않으므로 하위 호환성 문제가 발생하지 않는다.
- 신규로 열린 기능: 국내 주식 시가단일가(장 개시, OPG) 주문을 `LIMIT`/`MARKET` 모두로 낼 수 있게 됨.

## 권장 후속 조치

1. `orderintent.PlaceIntent` 에 `TimeInForce` (또는 유사) 필드를 추가하고, `--time-in-force`(가칭) CLI 플래그로 `DAY`/`CLS`/`OPG` 중 선택할 수 있게 확장하는 것을 검토한다.
   - 현재는 `LIMIT` 주문에서만 `TimeInForce` 를 보내므로, `OPG`+`MARKET` 조합을 지원하려면 `buildOrderCreate()` 의 `if orderType == "LIMIT"` 분기 밖에서도 `TimeInForce` 를 세팅하도록 로직을 손봐야 한다.
   - `OPG` 는 국내 주식 전용이므로 해외(US) 심볼에 대해서는 거부하거나 무시하는 가드가 필요하다.
   - 세션 시간(장전 사전접수) 외 접수 시 원장에서 거절될 수 있다는 문서 각주를 사용자 안내 문구에 반영한다.
2. 즉시 조치는 불필요 (no-op 아님이지만 breaking 도 아님) — 다음 기능 스프린트에서 우선순위 판단.
