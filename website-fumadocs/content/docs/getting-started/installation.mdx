---

`tossctl` 은 단일 실행 바이너리입니다. macOS·Linux·Windows를 지원합니다.

## macOS / Linux (한 줄 설치)

```bash
curl -fsSL https://raw.githubusercontent.com/JungHoonGhae/tossinvest-cli/main/install.sh | sh
```

다운로드·체크섬 검증 후 기본 `/usr/local/bin`에 설치합니다. 이 경로가 PATH에 포함되어 있어야 합니다.

## Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/JungHoonGhae/tossinvest-cli/main/install.ps1 | iex
```

## Homebrew

```bash
brew install JungHoonGhae/tossinvest-cli/tossctl
# 업그레이드
brew upgrade tossctl
```

## 소스 빌드 (Go 1.25.13 이상)

```bash
go install github.com/JungHoonGhae/tossinvest-cli/cmd/tossctl@latest
```

## 사전 요구사항

- **WTS 로그인(`auth login`)에는 Google Chrome, Python 3.11+, Playwright와 auth-helper가 필요**합니다. 설치 스크립트는 auth-helper를 배치하고 Python이 있으면 의존성 설치를 시도합니다. Chrome·Python 자체를 자동 설치하지는 않습니다.
- `go install`은 바이너리만 설치합니다. WTS 로그인도 필요하면 릴리즈의 auth-helper를 함께 설치하거나 저장소의 [`auth-helper/README.md`](https://github.com/JungHoonGhae/tossinvest-cli/blob/main/auth-helper/README.md)를 따르세요.
- 공식 API 호출에는 공식 키가, WTS 호출에는 유효한 웹 세션이 필요합니다. 빠진 의존성과 인증 상태는 `tossctl doctor`로 확인합니다.

## 설치 확인

```bash
tossctl version
tossctl doctor
```

`doctor` 는 바이너리·Chrome·Python·세션·엔드포인트 상태를 점검합니다. 문제가 있으면
`tossctl doctor --report` 로 JSON 진단(홈 경로 자동 마스킹)을 만들어 이슈에 붙일 수 있습니다.
