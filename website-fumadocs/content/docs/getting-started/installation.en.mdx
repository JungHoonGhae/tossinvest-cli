---
title: Install
description: Install tossctl (macOS·Linux·Windows·Homebrew·source)
---

`tossctl` is a single binary. macOS, Linux, and Windows are supported.

## macOS / Linux (one line)

```bash
curl -fsSL https://raw.githubusercontent.com/JungHoonGhae/tossinvest-cli/main/install.sh | sh
```

Downloads, verifies the checksum, and installs to `/usr/local/bin` by default. Ensure that directory is on your PATH.

## Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/JungHoonGhae/tossinvest-cli/main/install.ps1 | iex
```

## Homebrew

```bash
brew install JungHoonGhae/tossinvest-cli/tossctl
# upgrade
brew upgrade tossctl
```

## From source (Go 1.25.13 or later)

```bash
go install github.com/JungHoonGhae/tossinvest-cli/cmd/tossctl@latest
```

## Prerequisites

- **WTS login (`auth login`) requires Google Chrome, Python 3.11+, Playwright, and auth-helper.** Installers place auth-helper and attempt dependency installation if Python is available. They do not install Chrome or Python themselves.
- `go install` installs only the binary. For WTS login, also install the release's auth-helper or follow [`auth-helper/README.md`](https://github.com/JungHoonGhae/tossinvest-cli/blob/main/auth-helper/README.md).
- Official calls require an official key; WTS calls require a valid web session. Run `tossctl doctor` to check missing dependencies and credentials.

## Verify

```bash
tossctl version
tossctl doctor
```

`doctor` checks the binary, Chrome, Python, session, and endpoint health. If something is
off, `tossctl doctor --report` produces a JSON diagnostic (home paths auto-masked) you can
attach to an issue.
