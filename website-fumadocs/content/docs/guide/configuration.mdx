설정 파일 위치는 OS별 사용자 설정 디렉터리이며, `tossctl config status` 로 경로와 현재
상태를 확인할 수 있습니다.

```bash
tossctl config status
```

## 주요 항목

```json
{
  "schema_version": 5,
  "trading": {
    "place": false,
    "sell": false,
    "fractional": false,
    "cancel": false,
    "amend": false,
    "conditional": false,
    "allow_live_order_actions": false,
    "dangerous_automation": {
      "accept_fx_consent": false
    }
  },
  "update_check": {
    "enabled": true
  },
  "experimental": {
    "paper_trading": false
  }
}
```

| 키 | 설명 |
|----|------|
| `trading.place`·`cancel`·`amend`·`conditional` | 각 주문 경로 허용 여부 |
| `trading.sell` | `place`가 켜진 상태에서 매도까지 허용 |
| `trading.fractional` | `place`가 켜진 상태에서 미국주식 소수점 주문 허용 |
| `trading.allow_live_order_actions` | 모든 실계좌 주문의 마스터 킬스위치 |
| `trading.dangerous_automation.accept_fx_consent` | 환전이 필요한 지원 주문에서 서버 동의를 자동 수락 |
| `update_check.enabled` | 새 버전 알림 on/off (자동화 출력은 오염시키지 않음) |
| `experimental.paper_trading` | 롤아웃 중인 미국 옵션 모의투자 CLI·ops/MCP·전용 probe 노출. 기본 `false` |

모의투자는 다음 명령으로 명시적으로 옵트인합니다.

```bash
tossctl config experimental paper-trading --enable
```

모의 원장 쓰기는 기본 preview이며 `--execute`가 있어야 적용됩니다. 실계좌 config나 confirm
token을 재사용하지 않으며, `paper order live-preview`도 실주문을 제출하지 않습니다.

- 스키마 버전은 자동 관리되며, 오래된/사용되지 않는 항목이 있으면 실행 시 한 줄 안내가
  나오고 `config status`·`doctor` 가 표시합니다.
- `trading.grant`는 제거된 legacy 키이며 남아 있어도 무시됩니다.
- 설정 스키마(JSON Schema)는 저장소의
  [`schemas/config.schema.json`](https://github.com/JungHoonGhae/tossinvest-cli/blob/main/schemas/config.schema.json)
  에 있습니다.

## 진단

```bash
tossctl doctor            # 사람용 점검
tossctl doctor --report   # JSON 진단 (홈 경로 마스킹, 이슈 첨부용)
```

거래 보호 장치는 [안전 모델](/docs/guide/safety)에서 자세히 다룹니다.
