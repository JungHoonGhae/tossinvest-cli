**Toss Securities beyond the official API, through CLI and MCP.** The binary is `tossctl`.

Combine official accounts, quotes, and orders with WTS-only investor flows, AI signals, dividends,
and watchlists. Use the CLI in terminals and scripts, or MCP with AI agents. Official keys and
WTS web sessions are separate credentials; each feature checks the authentication it needs.

<Callout type="warn" title="Unofficial project">
  This is not an official Toss Securities product. It uses the internal web API unofficially, which may
  violate the Terms of Service. The API can change without notice, and the author takes no responsibility
  for account restrictions, losses, or other consequences. Use at your own risk.
</Callout>

<Callout type="error" title="Trading is off by default">
  All trading is disabled after install. It runs only after you enable it in `config.json`, and live
  orders require a two-step `--execute` + `--confirm <token>`. See [Safety Model](/en/docs/guide/safety).
</Callout>

## At a glance

- **Combines the official API with WTS.** Supported reads prefer the official API by default; WTS-only features need a web session.
- Features the official API lacks: investor flows, indices, detailed index quotes, AI signals, news
  briefing, screener, dividends, sector moves, community rankings, watchlist management, ledger,
SSE push, and dry-run preview.
- Output: table · JSON · CSV · SSE — ready for automation and agent pipelines.

The current scope is **Toss Securities**, not general Toss banking or card spending. US-options paper trading requires a separate opt-in. See [Support Scope](/en/docs/reference/support-scope) for the full comparison.

## Install and run your first query

```bash
curl -fsSL https://raw.githubusercontent.com/JungHoonGhae/tossinvest-cli/main/install.sh | sh

tossctl doctor
tossctl auth login
tossctl account summary --output json
```
