**공식 Open API와 WTS 전용 기능의 지원 범위를 비교합니다.** 구현 여부와 실제 이용 가능 여부는 다릅니다. 인증·이용 자격·거래 시간·서버 상태에 따라 호출이 제한될 수 있습니다. 자세한 설정 방법은
[하이브리드 가이드](/docs/guide/hybrid-openapi)를 참고하세요.

- ✅ 지원 · ❌ 미지원 · 🔸 부분 지원 · 🆕 최근 30일 내 추가 또는 아직 미출시
- `공식 API` 칼럼은 공개 계약 기준입니다. 실제 제출 경로는 명령별 정책과 설정을 따릅니다.
- 공식이 ❌인 행은 WTS 추가 기능 또는 로컬 기능입니다. CSV·preview 자체는 WTS endpoint가 아닙니다.

README의 **30+ 추가 기능**은 아래 표에서 공식 API가 ❌이고 tossctl이 ✅인 기능을
기준으로 하며, 로컬 CSV 내보내기·주문 미리보기·실험적 모의투자는 제외합니다.
한 행이 여러 호출을 묶기도 하므로 개별 endpoint 수와는 다릅니다.

2026-09-12에 [공식 Open API 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)
**1.2.15**와 대조했습니다. 공식 API도 국내 투자자별
매매동향, 거래량·거래대금·등락률 랭킹, 일부 시장 지표, 다건 시세를 제공합니다.
이 영역은 WTS와 범위·필드가 달라 아래에서 부분 지원으로 표시하며 추가 기능 수에 넣지 않습니다.

## 기능 영역 ≠ 접근 경로

`증권`·`Banking`·`MyData`는 기능 영역이고, 공식 Open API·WTS·mobile은 접근 경로입니다.
WTS는 **토스증권 Web Trading System**이며 일반 Toss Banking의 웹앱이 아닙니다.

| 기능 영역 | 접근 경로 | 현재 지원 |
|---|---|---|
| 토스증권 | official, WTS, Toss 앱 안의 증권 모바일 화면 | official + WTS |
| 일반 Banking | 일반 Toss 앱 mobile API (대응 WTS 없음) | 미지원 — 별도 모바일 인증 필요 |
| MyData 카드·소비 | 일반 Toss 앱 mobile API | 정적 계약 일부 확인, 미지원 |
| 시스템 | 로그인·Open API IP·변경 감시 | 지원 |

정식 명령 `accumulate funding-status`는 증권 주식모으기의 자금연결 상태로,
`securities + wts`에 속합니다. 이전 `banking status`는 deprecated alias입니다. 자동주문 자금연결도
증권 주문 절차에 한정되며 일반 Banking 데이터 접근을 뜻하지 않습니다.

웹 UI 부재 자체는 미지원 이유가 아닙니다. WTS 계약과 현재 웹 세션이 검증되면 UI 없이도
호출할 수 있습니다. 일반 Banking/MyData는 API 계약이 없어서가 아니라 main-app session,
app/device header, request/response cipher를 처리하는 mobile connector가 아직 없어서 미지원입니다.

## `openapi` 커맨드

| 커맨드 | 설명 |
|--------|------|
| `tossctl init` | 온보딩 위저드 — 세션·공식 키·거래 설정을 단계별 안내 |
| `tossctl openapi login` | 공식 키 등록 (환경변수 `TOSSCTL_OPENAPI_KEY`/`TOSSCTL_OPENAPI_SECRET` 또는 플래그) |
| `tossctl openapi status` | 키·토큰·허용 IP·라우팅 상태 진단 |
| `tossctl openapi test` | 실제 API 호출로 연결 검증 |
| `tossctl openapi ip list` | 허용 IP 조회(WTS 세션 필요) |
| `tossctl openapi ip replace-current` | 현재 공인 IP 교체 preview/confirm |
| `tossctl openapi logout` | 자격증명 파일 삭제 |

전역 플래그 `--backend auto|wts|openapi` 로 요청별 라우팅을 직접 지정할 수 있습니다.

## 조회·설정 지원

조회와 변경을 함께 제공하는 행이 있습니다. `add/remove`, `hide/show`, 관심종목 변경은 쓰기이며 [안전 모델](/docs/guide/safety)의 preview·confirm 정책을 따릅니다.

| 기능 | 명령 | 공식 API | tossctl |

| 계좌 목록 / 요약 | `account list`, `account summary` | ✅ | ✅ |

| 🆕 증권 주식이체 계좌 조회 | `account transfer-accounts [--account <key>] [--full]` (번호 기본 마스킹, 이체 실행 없음) | ❌ | ✅ |
| 🆕 증권 접속·계좌 제한 상태 | `account access-status [--account <key>]` (최근 접속, 신용거래 동결, 사고계좌 수; 변경 없음) | ❌ | ✅ |

## 거래

| 기능 | 명령 | 공식 API | tossctl |
|------|------|:--:|:--:|
| 매수·매도 주문 | `order place` | ✅ | ✅ |
| 주문 취소·정정 | `order cancel`, `order amend` | ✅ | ✅ |
| dry-run preview | `order preview` | ❌ | ✅ |
| 소수점 주문 (US, 금액/수량) | `order place --fractional` | ✅ | ✅ |
| 소수점 주문 — 원화(KRW) 결제 | `order place --fractional --currency-mode KRW` | ❌ | ✅ |
| 실시간 푸시(SSE) | `push listen` | ❌ | ✅ |

<Callout type="info" title="소수점 매도 (beta)">
  공식 Open API 1.1.5에 추가된 **미국 시장가 소수점 수량 매도**(`order place --fractional --side sell --qty 0.5`, 소수점 6자리)를 구현했습니다. 계약 테스트는 통과했으나 **라이브 검증은 아직**입니다 — 실거래 전 `order preview`로 확인하세요. 소수점 매수는 기존대로 금액 기반(`--amount`)입니다.
</Callout>

## 실험적 미국 옵션 모의투자

기본적으로 숨겨져 있으며 `tossctl config experimental paper-trading --enable`로 옵트인합니다. CLI의 `paper status/init/deposit`, `paper order place/cancel/live-preview`, `paper orders pending/completed/cancel-all`을 제공하고 MCP에는 8개 오퍼레이션, monitor에는 4개 probe가 추가됩니다.

2026-09-03 관측에서 모의 주문 생성·취소는 동작했지만 초기화 500과 교육 상태 불일치가 남았습니다. 모든 사용자에게 제공되거나 안정화되었다는 뜻은 아닙니다. 최신 관측은 아래 WTS 기록의 `rolling_features`를 확인하세요. 실거래 권한과는 분리됩니다.

## 검증 기준

`공식 API` 칼럼은 [공식 Open API 문서](https://developers.tossinvest.com/docs)의 특정
버전 기준으로 검증됩니다. 검증된 버전·마지막 점검일은 저장소의
[`.openapi-snapshot.json`](https://github.com/JungHoonGhae/tossinvest-cli/blob/main/docs/migration/.openapi-snapshot.json)
에 기록되며, 전체 spec 사본을 매일 미러링하고 변경 시 자동 감지·갱신합니다.

WTS 웹 API 전체 카탈로그(구현/다음 추가 후보/의도적 제외)는
[`wts-endpoints.json`](https://github.com/JungHoonGhae/tossinvest-cli/blob/main/docs/reverse-engineering/wts-endpoints.json)
에서 지속 추적합니다.
